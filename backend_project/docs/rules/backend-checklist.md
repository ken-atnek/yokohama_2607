# バックエンド確認チェックリスト

## 使い方

すべての項目を機械的に確認するのではなく、変更内容に関係する項目だけ使用します。

## PHP

- [ ] 対象PHPの入口とinclude / require構成を確認した
- [ ] PHPバージョン互換性を確認した
- [ ] `php -l {file}` を実行した
- [ ] 例外時のレスポンスまたは終了コードを確認した
- [ ] `header()` 後に必要な `exit` がある

## SQL / DB

- [ ] 対象DBと対象テーブルを確認した
- [ ] 既存DDL、型、制約、indexを確認した
- [ ] prepared statementを使用している
- [ ] UPDATE / DELETE のWHERE条件が適切
- [ ] 店舗IDや所属チェックが必要な箇所を確認した
- [ ] transactionとrollback可能性を確認した
- [ ] MyISAM / InnoDBなどの差異を確認した

## セキュリティ

- [ ] SQL Injection対策
- [ ] XSS対策
- [ ] CSRF対策
- [ ] 認証
- [ ] 認可
- [ ] SESSION / Cookie
- [ ] tokenの有効期限と1回使用制御
- [ ] ログに秘密情報や個人情報を出していない

## API

- [ ] HTTPメソッドが仕様通り
- [ ] Content-Typeを確認している
- [ ] 入力値検証がある
- [ ] HTTPステータスが仕様通り
- [ ] JSONレスポンス形式が既存実装と一致している
- [ ] Next.js側の呼び出し元と整合している

## JSON

- [ ] 既存JSONキーを壊していない
- [ ] `CastList.json` / `details.json` / `schedule.json` / `realtime.json` などの参照先を確認した
- [ ] フロント側の型・読み込み処理と整合している
- [ ] 生成元PHPと出力先を取り違えていない

## SESSION

- [ ] セッション開始位置を確認した
- [ ] セッション固定化対策が必要か確認した
- [ ] 認証後の有効期限を仕様書で確認した
- [ ] DB上の状態再確認が必要なAPIで再確認している

## メール

- [ ] 受付メールアドレスを仕様書で確認した
- [ ] From / To / Subjectの解析仕様を確認した
- [ ] MIMEデコードと文字コード処理を確認した
- [ ] 自動返信、空メール、認証メール、設定リンクメールの区別を確認した
- [ ] 本番送信フラグとdry-runを確認した
- [ ] 送信ログに秘密情報を出していない

## cron / batch / CLI

- [ ] `PHP_SAPI` の制御を確認した
- [ ] Webアクセス禁止設定を確認した
- [ ] 引数仕様を確認した
- [ ] 再実行可能性を確認した
- [ ] apply / dry-runの違いを確認した
- [ ] cron登録は明示指示なしに変更していない

## ファイル操作

- [ ] 公開パスと非公開パスを確認した
- [ ] path traversal対策を確認した
- [ ] Webから見せてはいけないファイルを置いていない
- [ ] `.htaccess` またはサーバー設定の影響を確認した

## テスト・確認

- [ ] 構文確認を実行した
- [ ] 既存テストがある場合は対象範囲を確認した
- [ ] 手動確認手順を残した
- [ ] 実行できない確認がある場合は理由を残した
- [ ] Codexの採否判断をChatGPTでレビューした
- [ ] 修正後Claude再レビューの要否を判断した
- [ ] PHPロジック、SQL / DB、認証、認可、SESSION、CSRF、API、メール、cron / CLI、個人情報、token、ファイル操作、JSON生成、複数ファイル、セキュリティに関わる修正では修正後Claude再レビューを実施した
- [ ] コメント、typo、文言、ドキュメントのみの修正で修正後Claude再レビューを省略した場合は理由を残した

## git diff

- [ ] `git status` で既存変更と今回変更を切り分けた
- [ ] `git diff` で依頼外変更がないことを確認した
- [ ] 新規ファイルの内容を確認した
- [ ] 実コードを整理目的だけで移動していない
- [ ] 修正後Claude再レビューに渡す修正後diffを確認した

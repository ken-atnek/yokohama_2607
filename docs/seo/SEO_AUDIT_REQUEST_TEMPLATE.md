# SEO総合チェック依頼テンプレート（静的書き出し向け）

## 依頼内容
このプロジェクト全体について、SEO観点で総合チェックをしてください。

## 前提
- Next.js を使用
- 静的書き出し（`output: 'export'`）で運用
- 実装済みのコード・設定・ページ構成を実際に確認したうえで判断すること
- 一般論ではなく、このプロジェクトに対する具体的な指摘を行うこと
- 判定は `npm run build:prod` 実行後の `out/` 生成物も根拠に含めること

## 必須チェック対象ページ
- `/`
- `/roots`

## 確認してほしい内容

### 1. メタ情報
- 各ページの `title`
- `description`
- `metadata`
- OGP / Twitter Card
- canonical
- robots 関連
- ページごとに適切に出し分けできているか
- 重複や不足がないか

### 2. 見出し構造
- `h1` が各ページに適切に存在するか
- `h1` の重複や複数使用がないか
- `h2` 以降の階層が自然か
- デザイン目的だけで見出しタグを使っていないか

### 3. HTML構造・クローラビリティ
- `main`, `header`, `nav`, `footer`, `section`, `article` などの使い方
- コンテンツの意味構造が適切か
- クローラーに伝わりにくい実装がないか
- テキストで持つべき情報が画像だけになっていないか

### 4. 内部リンク・URL設計
- 主要ページへの内部リンク構造
- パンくずリストの有無と実装余地
- URLがSEO上わかりやすいか
- クエリパラメータ運用がSEO上問題になりそうな箇所がないか
- リンクテキストが適切か

### 5. 画像SEO
- `alt` の不足・不適切な記述
- 装飾画像と意味のある画像の扱い
- 画像ファイル名や読み込み方で気になる点
- `next/image` や静的書き出し前提での懸念点

### 6. 構造化データ
- このサイトで導入を検討すべき schema.org の種類
- すでに入っている場合は妥当性
- 未導入の場合、SEO上優先度が高いもの
- どのページに何を入れるべきか

### 7. インデックス制御
- `sitemap.xml`
- `robots.txt`
- noindex が必要なページの有無
- 逆に index されるべきなのに弱いページがないか

### 8. コンテンツSEO
- ページ単位で情報量が不足していそうな箇所
- 検索意図に対して弱そうなページ
- タイトルや説明文が抽象的すぎる箇所
- 一覧ページ・詳細ページで差別化が弱い箇所

### 9. 技術SEO
- 静的書き出し前提でSEO上気になる実装
- JavaScript依存が強すぎる箇所
- hydration後にしか出ない重要情報がないか
- パフォーマンスや Core Web Vitals に影響しそうなSEO上の懸念

## 出力形式
以下の形式でまとめてください。

1. **総評**
   - 現状のSEO実装レベル
   - 大きな問題があるかどうか

2. **優先度：高**
   - 必ず修正した方がよい点
   - 対象ファイル・対象ページ
   - なぜ問題か
   - どう直すべきか

3. **優先度：中**
   - 改善するとSEO上プラスになりそうな点

4. **優先度：低**
   - 余裕があれば整えたい点

5. **ページ別チェック**
   - 主要ページごとに気になる点を整理

6. **不足しているSEO施策一覧**
   - まだ未実装と思われるものを一覧化

7. **修正に入る場合のおすすめ順**
   - どこから手を付けるべきか、実装順で提案

## 記述ルール（必須）
- いきなりコード修正はせず、まずはチェック結果と改善方針だけを出すこと
- 指摘は、実際にファイルを確認して根拠を持って行うこと
- 推測だけで断定しないこと
- 各指摘に `ファイルパス:行番号` または `out配下HTMLの該当箇所` を必ず添えること

# SEO修正トラッカー（運用テンプレート）

## 使い方
- 診断結果をこのファイルに転記し、対応ステータスを管理する
- 1項目ごとに「何を」「どこまで」「誰が」を明確にする
- 迷う項目は先に `保留` にして、判断理由だけ先に残す

## ステータス定義
- `未着手`: まだ対応していない
- `対応中`: 実装または検証中
- `対応済み`: 実装と確認が完了
- `保留`: 方針判断待ち
- `対応不要`: 現プロジェクト方針上、対応しない

## 管理テーブル
| ID | 優先度 | 指摘内容 | 対象ページ/URL | 対象ファイル | 対応方針 | ステータス | 担当 | 期限 | 備考 |
|---|---|---|---|---|---|---|---|---|---|
| SEO-001 | 高 | 例: `/roots` の `title` が個別化できていない | `/roots` | `src/app/roots/page.tsx` | 共通メタ運用を維持し、将来はパス型URLに切替検討 | 対応中 |  |  | `output: 'export'` 制約あり |

## 保留事項
- 方針判断が必要な項目を列挙
- 判断期限と判断者を記載

## 次回レビュー時チェック
- `title` / `description` の重複有無
- `robots.txt` / `sitemap.xml` の整合
- 主要ページの `h1` と見出し階層
- 画像 `alt` の不足
- 構造化データ導入対象の再判定

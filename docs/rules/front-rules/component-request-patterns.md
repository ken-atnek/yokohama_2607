# コンポーネント作成依頼ルール

## 目的

コンポーネント作成依頼の粒度をそろえ、実装者と依頼者の認識ズレを減らす。  
このルールでは、コンポーネント作成依頼を `仮置き` と `最小実装` の2パターンに分けて扱う。

---

## パターン一覧

| パターン | 用途 | 作成粒度 |
|---|---|---|
| 仮置き | 後で自分で中身を書く前提 | 外枠だけ |
| 最小実装 | キャプチャーを参考に先に土台を組みたい | 大枠レイアウトまで |

### 先に判断すること

- 依頼文に `仮置き` とある場合は、ほかに `キャプチャー確認` `参考画像あり` などの文言があっても `仮置き` として扱う
- `キャプチャーを確認して` は、構成把握のための確認指示として扱う
- キャプチャーを見たうえで実装粒度を上げてよいのは、`最小実装` と明記されている場合だけ
- 判断に迷ったら、必ず `仮置き` 側の小さい粒度で止める

---

## パターンA: 仮置き

### 目的

ファイルと骨組みだけ先に作成し、文言・画像・見た目の実装は後から手動で入れる。

### やること

- `tsx` と `module.scss` を新規作成する
- コメントヘッダーを記載する
- `tsx` はセクションの大枠だけ作る
- `scss` は対応する class の空ブロックだけ作る
- 必要なら `page.tsx` や親コンポーネントへ差し込む
- 自分で後から打ちやすい、シンプルな構造にする

### やらなくていいこと

- 文言の流し込み
- 画像の本実装
- キャプチャーに合わせた見た目づくり
- レイアウトの細かい調整
- hover 演出
- アニメーション
- パララックス
- レスポンシブ調整
- 装飾の作り込み

### 依頼文テンプレート

```md
`TopRooms.tsx` と `TopRooms.module.scss` を新規作成してください。
自分で中身を書くので、外枠だけでOKです。
TSX は骨組みだけ、SCSS は対応 class の空ブロックだけ用意してください。
必要なら `page.tsx` にも差し込んでください。
```

### 短い依頼文

```md
`TopRooms.tsx` と `TopRooms.module.scss` を作成。
外枠だけ設置してください。
TSX は骨組みのみ、SCSS は対応 class の空ブロックのみでOKです。
必要なら `page.tsx` にも追加してください。
```

### 補足例

```md
キャプチャーを確認して、`TopHero.tsx` と `TopHero.module.scss` を仮置きしてください。
```

この場合も `仮置き` 扱いです。  
キャプチャー確認は構成把握までに留め、`tsx` は骨組みだけ、`scss` は空ブロックだけにします。

## パターンB: 最小実装

### 目的

キャプチャーや参考画像をもとに、あとで詰めやすい最小構成まで先に組む。

### やること

- `tsx` と `module.scss` を新規作成する
- コメントヘッダーを記載する
- キャプチャーを参考に、大まかな構造を組む
- 必要最小限の文言・画像・リンク枠を入れる
- 大枠レイアウトが分かる程度の SCSS を入れる
- 必要なら `page.tsx` や親コンポーネントへ差し込む

### やらなくていいこと

- 完全再現
- 細かい余白調整
- 本番用の hover 演出
- 本番用のアニメーション
- 本番用のパララックス
- スマホ最適化の細部調整
- コンテンツの最終確定

### 依頼文テンプレート

```md
添付キャプチャーを参考に、`TopNews.tsx` と `TopNews.module.scss` を最小構成で作成してください。
まずは大枠レイアウトが分かる程度でOKです。
文言・画像・リンクは仮で入れてよく、あとで調整しやすい形にしてください。
必要なら `page.tsx` にも差し込んでください。
```

### 短い依頼文

```md
キャプチャー参考で `TopNews.tsx` と `TopNews.module.scss` を最小実装してください。
大枠だけ組んで、あとで詰めやすい状態にしてください。
必要なら `page.tsx` にも追加してください。
```

---

## 依頼時に明記すること

依頼時は、次のどちらかを必ず明記する。

- `仮置きでお願いします`
- `キャプチャー参考の最小実装でお願いします`

この指定がないと、実装粒度がずれやすい。

---

## 共通ルール

- `tsx` と `module.scss` は同階層に置く
- ページ単位の専用コンポーネントは用途が分かる名前にする
- 既存構造に合わせる
- 勝手に大きく作り込みすぎない
- 判断に迷ったら、より小さい粒度で止める
- `page.tsx` にはセクションを並べるだけの構造を保つ

---

## 一言指定

- `仮置き`
  = キャプチャー有無に関係なく、骨組みだけ
- `最小実装`
  = キャプチャー参考で大枠だけ組む
